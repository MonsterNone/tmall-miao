## 前置条件（只需做一次）

### 1. 开启手机的开发者选项和 USB 调试（各品牌略有差异）

### 2. 安装 ADB 工具

下载 [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)，解压后将目录加入系统 PATH。

```bash
adb version
# Android Debug Bridge version 1.0.41 ...
```

### 3. 安装 Python 依赖

```bash
cd tmall-miao/android
pip install -r requirements.txt
```

---

## 首次初始化（每台新设备必须做一次）

### 步骤 1：连接设备

USB 数据线连接电脑，手机上点击「允许 USB 调试」。

验证连接：

```bash
adb devices
```

输出：

```
List of devices attached
ABC123456789    device      # device 表示已授权
```

如果显示 `unauthorized`，检查手机屏幕有没有弹出授权框。

### 步骤 2：初始化 uiautomator2 服务

```bash
python -m uiautomator2 init
```

这个过程会：

1. 向手机推送 `u2.jar`（自动化服务）
2. 安装 `AdbKeyboard` 输入法（用于 `send_keys` 输入中文）
3. 启动 uiautomator2 后台服务（监听端口 9008）

成功标志：

```
successfully installed, time used X.X seconds
```

### 步骤 3：验证服务正常

```bash
python -c "import uiautomator2 as u2; d = u2.connect(); print(d.device_info)"
```

如果能打印出设备信息（型号、分辨率等），说明一切就绪。



## 开始使用

```bash
cd tmall-miao/android
python main.py
```
